# ML Strategy Analogy

Use machine learning vocabulary as a design analogy, not as a new domain model.

- model ~= ML model: transforms inputs into predictions, scores, or signals.
- strategy ~= ML inference pipeline: uses models, rules, and portfolio logic to
  produce portfolio decisions.
- strategy checkpoint ~= ML checkpoint: saved strategy state that can be loaded
  later.
- dataset ~= ML dataset: the data a model or strategy is run against.
